# Tastes of Africa

A multi-page website celebrating African food, with 7 recipes across West, East, North and Southern Africa. Built with HTML, CSS and JavaScript.

**Live site:** https://github.com/Chris12908/taste_of_africa_website_project
**Author:** Chris Marcel Hakizimana

## Pages
Home, Recipes, Regions (4 region pages), 7 recipe pages, About Us, Contact.

## Features
- Semantic HTML5 with `<details>`, `<figure>` and `<mark>`
- Responsive layout with Google Fonts (Bowlby One, Atkinson Hyperlegible)
- Recipe filter by region
- Favorites saved in `localStorage`
- Contact form validation (message over 20 characters)
- Ingredient scaler and dark/light mode
- Embedded YouTube videos and Google Maps

## Run locally
Open the folder in VS Code and use **Live Server** on `index.html`.
